# FinSight — Decision Intelligence Platform

> **Ask your business anything. Get a decision, not just a number.**

FinSight is an AI-powered financial decision intelligence platform designed to help businesses understand their financial data, identify risks, forecast cash flow, and make better decisions.

## 🚀 Core Flow

**ASK → RETRIEVE → COMPUTE → REASON → EXPLAIN → RECOMMEND**

FinSight combines deterministic financial calculations with AI-powered reasoning to transform financial data into actionable business recommendations.

## ✨ Features

- 📊 Financial performance dashboard
- 💰 Revenue, expense, and cash-flow analysis
- 📈 Cash-flow forecasting
- ⚠️ Financial anomaly detection
- 🏢 Vendor analysis
- 🧾 Invoice analysis
- 🎯 Budget analysis
- 👥 Hiring decision evaluation
- 🛒 Purchase decision evaluation
- 💳 Loan decision evaluation
- 📉 Expense-reduction analysis
- 💼 Budget-change analysis
- 🤖 AI financial assistant
- 🧠 Qwen-powered financial reasoning
- 🔎 Evidence-based recommendations
- 📌 Risk scoring and explainability
- 🇮🇳 INR / Indian number formatting

🔐 Design Principles

FinSight separates financial computation from AI reasoning.

Financial calculations are deterministic and auditable. AI is used for reasoning, explanation, and recommendations rather than inventing financial numbers.

Financial outputs use provenance labels:

ACTUAL — source data
CALCULATED — derived values
FORECAST — projected values
SCENARIO — decision simulations

Risk levels:

LOW
MEDIUM
HIGH
CRITICAL
